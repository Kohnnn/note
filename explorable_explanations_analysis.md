# Interactive Explanations: Technical & Architectural Analysis

Based on the prompt, this repository analyzes interactive explanation websites referenced in prominent curations. The goal is to provide granular, "super minute" details on their interactive elements and tech stacks to serve as a blueprint for replicating them.

I have separated the detailed analysis for each site into dedicated pages:

1. [AWS MLU-Explain](./aws-mlu-explain.md) - A deep dive into Amazon's scrollytelling educational platform (Svelte + D3.js).
2. [Bartosz Ciechanowski Blog](./ciechanow-ski.md) - An analysis of high-performance, interactive 3D mechanical models (Custom WebGL/Canvas).
